
 How to handle ubuntu test images

== Build base ubuntu
=== from scratch:

    sudo docker pull ubuntu:latest                                   # ':latest' is optional
    sudo docker run --rm -it --name ubuntu26 ubuntu /bin/bash        # Identify latest version beforehand, his runs a shell inside
        apt update
        apt install lsb-release
    sudo docker commit ubuntu26 ubuntu26                             # Saves a generic base image

=== ubuntu26 already exists:

    sudo docker run --rm -it --name ubuntu26 ubuntu26 /bin/bash     # Identify latest version beforehand, his runs a shell inside
